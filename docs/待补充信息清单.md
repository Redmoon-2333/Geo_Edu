# GeoEdu 待补充信息清单

> 本文档汇总 GeoEdu 项目需要进一步明确的信息项，供团队后续讨论和决策。AI 推荐值仅供参考，最终以团队确认为准。

## 1. 知识库规范

### 1.1 知识点录入

| 待确认项 | 说明 | AI 推荐 | 备注 |
|---------|------|---------|------|
| ID 格式 | 知识点唯一标识格式 | `G{年级}-{章节}-{序号}` | 例：G1-1-01 |
| 正文模板 | 知识点正文标准格式 | 定义 + 核心要点 + 典型案例 + 常见误区 | 4 部分结构 |
| 难度等级 | easy/medium/hard 划分标准 | easy（识记）/ medium（理解）/ hard（应用） | 分类清晰 |
| 章节规则 | 章节编号与教材目录对应 | 按教材目录章节号 | G1-1 表示必修一第1章 |

### 1.2 图文匹配

| 待确认项 | 说明 | AI 推荐 | 备注 |
|---------|------|---------|------|
| 图片数量 | 每个知识点配图数量 | 1-2 张（不强制的可选） | 非强制但建议 |
| 图片规格 | 分辨率、格式、命名 | 最大边1920px，JPEG/PNG，命名：`{知识点ID}_{序号}.jpg` | 自动压缩优化 |
| 图片来源 | 版权问题 | 优先使用教材示意图 / 自绘图 | 避免网络图片版权问题 |
| 替代文本 | caption/alt 文本 | 每张图片提供 caption | 用于配图说明 |

### 1.3 问答对

| 待确认项 | 说明 | AI 推荐 | 备注 |
|---------|------|---------|------|
| 问题来源 | 问题生成方式 | 教师预设 + 学生真实提问（试点后补充） | 双轨并行 |
| 问答数量 | 每个知识点问题数 | 3 个（初期可减少到 2 个） | 按需调整 |
| 答案字数 | 回答长度限制 | 150 字以内（不含标点） | 控制输出长度 |
| 分点规则 | 分点层级 | 最多 2 级分点，每级 1-3 点 | 避免过度细分 |

## 2. 技术架构

### 2.1 数据库

| 配置项 | 决策 | 说明 |
|--------|------|------|
| 数据库方案 | ✅ PostgreSQL + Redis-Stack | 已确认 |
| 向量检索 | ✅ Redis Stack Vector Search | 已确认 |
| 缓存方案 | ✅ Redis String/Hash | Token缓存、验证码缓存、热点缓存 |

### 2.2 部署环境

| 待确认项 | 说明 | AI 推荐 | 备注 |
|---------|------|---------|------|
| 目标服务器 | 部署方式 | 物理机或云服务器（试点阶段可用虚拟机） | 考虑 GPU 支持 |
| GPU 配置 | 推理加速 | 建议 NVIDIA 8GB+ 显存（可选，Qwen2.5-7B 可 CPU 运行） | CPU 模式较慢 |
| Docker 部署 | 容器化 | ✅ 使用 Docker-Compose 部署 | 简化运维 |
| 存储方案 | 图片存储 | 本地文件系统 `/data/images` | 初期足够，后续可迁移 MinIO |

### 2.3 模型配置

| 待确认项 | 说明 | AI 推荐 | 备注 |
|---------|------|---------|------|
| LLM 模型 | 主模型 | Qwen2.5-7B（qwen2.5:7b） | 中文能力强 |
| Embedding | 向量化模型 | nomic-embed-text（Ollama 内置） | 768 维，Ollama 原生支持 |
| 模型更新 | 版本管理 | 支持热更新，但初期固定版本 | 避免频繁变更 |
| 量化方案 | 精度优化 | INT4 量化（qwen2.5:7b-instruct-q4_0） | 降低内存占用 |

### 2.4 性能指标

| 待确认项 | 说明 | AI 推荐 | 备注 |
|---------|------|---------|------|
| 响应时间 | 端到端目标 | ≤ 3 秒（P95） | 含 AI 生成时间 |
| 并发用户 | 同时在线 | 50 用户（试点阶段足够） | 可扩展 |
| 向量精度 | ANN 召回率 | 95%+（HNSW 算法默认可达） | 够用就好 |
| 内存配置 | 服务器内存 | 16GB 最低，32GB 推荐 | Ollama 占用 4-6GB |

## 3. API 与安全

### 3.1 认证授权

| 待确认项 | 说明 | AI 推荐 | 备注 |
|---------|------|---------|------|
| Token 有效期 | JWT 过期时间 | 7 天（学生）/ 24 小时（敏感操作） | 平衡安全与便利 |
| 刷新机制 | Token 续期 | ❌ 暂不实现，用户重新登录 | 简化开发 |
| 游客访问 | 未登录用户 | ✅ 允许使用问答（仅查看历史需登录） | 降低门槛 |
| 多设备登录 | 同时在线 | ✅ 允许（无限制） | 避免用户体验问题 |

### 3.2 接口安全

| 待确认项 | 说明 | AI 推荐 | 备注 |
|---------|------|---------|------|
| HTTPS | 传输加密 | 开发环境可选，生产环境强制 | 数据安全 |
| 接口签名 | 请求验证 | ❌ 暂不实现 | 复杂度高 |
| IP 白名单 | 访问控制 | ❌ 暂不实现 | 试点阶段不需要 |
| 敏感词过滤 | 内容安全 | ✅ 实现基础违禁词过滤 | 必要 |
