# GeoEdu 项目关键问题咨询清单

---

## 一、功能需求澄清类

### 问题 1：错题本功能的触发机制是什么？

- 用户手动收藏错题？
- 系统自动记录答错的题目？
- 还是两者结合？

**影响**：决定是否需要 `user_error_record` 表和 `user_favorite` 表

---

### 问题 2：题库练习的题型范围是什么？

- 仅选择题（易于自动判分）？
- 还是包含填空、简答等主观题？
- 主观题如何实现自动判分？

**影响**：决定 `question` 表是否需要扩展 `question_type` 和 `standard_answer` 字段

---

### 问题 3："相关知识点题库练习"的推荐逻辑是什么？

- 基于用户当前学习的知识点？
- 基于用户错题分布的薄弱知识点？
- 还是基于知识点的难度梯度？

**影响**：决定推荐算法的复杂度

---

## 二、技术实现类

### 问题 4：大题判错的 AI 实时评分可行性确认

- 是否需要 AI 实时判断主观题答案的对错？
- 对评分准确率的要求是多少？
- 是否允许人工复核机制？

**影响**：决定是否需要额外的 AI 评分接口和评分日志表

---

### 问题 5：历史记录排序的维度优先级

- 时间排序（最新/最旧）
- 知识点分类
- 章节分类
- 错误率排序（针对练习题）
- 是否需要组合排序？

**影响**：决定后端查询接口的复杂度

---

### 问题 6：图片存储策略确认

- 相对路径的基准目录是什么？（如 `/data/images`）
- 是否需要 CDN 加速？
- 图片是否需要版本管理？

**影响**：决定 `image` 表是否需要 `version` 字段

---

### 问题 7：是否需要新增以下表结构？

```sql
-- 用户错题本
CREATE TABLE user_error_book (
    id VARCHAR(50) PRIMARY KEY,
    user_id VARCHAR(50),
    question_id VARCHAR(50),
    error_count INT,
    last_error_time TIMESTAMP,
    created_at TIMESTAMP
);

-- 用户收藏
CREATE TABLE user_favorite (
    id VARCHAR(50) PRIMARY KEY,
    user_id VARCHAR(50),
    knowledge_id VARCHAR(50),
    question_id VARCHAR(50),
    favorite_type VARCHAR(20), -- 'knowledge' or 'question'
    created_at TIMESTAMP
);

-- 用户练习记录
CREATE TABLE user_practice_record (
    id VARCHAR(50) PRIMARY KEY,
    user_id VARCHAR(50),
    question_id VARCHAR(50),
    user_answer TEXT,
    is_correct BOOLEAN,
    practice_time TIMESTAMP
);
```

**影响**：需要确认是否符合"不得修改数据库结构"的规则例外情况

### 问题 8：历史聊天记录的数据模型确认

当前 `chat_log` 表是否满足需求？是否需要扩展：

```sql
-- 方案 A：扩展现有 chat_log
ALTER TABLE chat_log ADD COLUMN error_rate DECIMAL(5,2);
ALTER TABLE chat_log ADD COLUMN session_id VARCHAR(50);
ALTER TABLE chat_log ADD COLUMN is_bookmarked BOOLEAN DEFAULT FALSE;

-- 方案 B：新增用户会话表
CREATE TABLE chat_session (
    id VARCHAR(50) PRIMARY KEY,
    user_id VARCHAR(50),
    session_type VARCHAR(20), -- 'qa'/'exercise'/'review'
    created_at TIMESTAMP,
    updated_at TIMESTAMP
);
```

**影响**：决定历史记录的查询效率和功能扩展性
