**项目构想：**

① 2026年 4-5月完成小规模试点，针对某一本教材或某两章教学内容，测试

② 2026年 6-9月反馈调整，适当扩大数据库至整个高中地理

③ 9-？，逐步面向初高中全学科（待定）

④2027年 实现项目投递参赛

**分工：**

1.  知识层面（知识库 + 教学逻辑）：

核心职责：构建权威知识库、设计教学逻辑、对接试点测试

  ------------ ---------------------------------------------------------------------------
  模块         具体任务
  教材结构化   人教版必修一按节拆分为知识点条目（ID、标题、正文、难度、页码），Excel整理
  图文匹配     为每个知识点匹配1-2张教材示意图，图片按知识点ID命名（如：G1-1-01_1.jpg）
  问答对生成   每个知识点编写3-5个典型学生问题，形成测试集
  回答规范     设计prompt模板：字数限制（150字内）、分点规则、术语解释方式
  试点对接     联系中学老师，收集使用需求，安排试点班级
  测试反馈     用测试集评估回答质量，记录badcase，反馈技术调整
  参赛材料     撰写项目申报书、制作路演PPT、整理演示素材
  ------------ ---------------------------------------------------------------------------

2.  技术层面一（后端核心 + AI对接）：

核心职责：Spring Boot后端、Ollama对接、RAG检索、API开发

  ------------ -----------------------------------------------------
  模块         具体任务
  环境搭建     Spring Boot项目初始化，Ollama本地部署（Qwen2.5-7B）
  数据库       设计知识点表、图片表、问答日志表
  知识库接口   提供知识库CRUD接口，方便地理同学录入数据
  检索实现     问题向量化 + 余弦相似度检索 + Top-K返回
  问答接口     /chat接口：检索→构造prompt→调用Ollama→返回答案+配图
  部署打包     打包JAR，编写启动脚本，确保离线可运行
  ------------ -----------------------------------------------------

3.  技术层面二（前端界面+交互）：

核心职责：Vue/React前端、UI设计、与后端联调

  ------------ -------------------------------------------------
  模块         具体任务
  数项目搭建   前端脚手架初始化，选择UI组件库
  问答界面     输入框 + 答案展示区（Markdown）+ 配图轮播区
  辅助功能     "教材原文"弹窗、"相关考题"折叠面板
  历史记录     问答历史列表，支持回看
  响应式       适配教室大屏（1920x1080）和学生平板（1024x768）
  联调部署     与后端联调，打包静态文件集成到JAR
  ------------ -------------------------------------------------

4.  技术层面三（数据接口 + 辅助工具 + 测试）：

核心职责：知识库管理工具、图片处理、测试与文档

  ---------- ---------------------------------------------------
  模块       具体任务
  管理界面   开发简易后台页面，供地理同学录入/编辑知识点和图片
  图片处理   图片上传接口、压缩优化、存储管理
  批量导入   Excel/JSON批量导入知识点功能
  测试用例   编写测试脚本，验证检索准确率和回答质量
  文档撰写   技术文档、部署手册、用户使用说明
  辅助联调   协助前后端联调，处理边界问题
  ---------- ---------------------------------------------------
